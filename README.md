# focus

A command-line Pomodoro / focus timer written in Java.

## Build
    mvn package
    java -jar target/focus.jar --help

## Development
After cloning, enable the pre-commit hook (format check + tests):

    git config core.hooksPath .githooks

## Documentation
API reference: https://j-alexander3375.github.io/focus-java/
Publish with `scripts/publish-docs.fish`.
